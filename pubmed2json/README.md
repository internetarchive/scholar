# pubmed2json

This code reads gzipped [pubmed update xml files](https://ftp.ncbi.nlm.nih.gov/pubmed/updatefiles/) and writes out equivalent entries as newline delimited json (ndjson).

It was created for use in scholkit so we could write ndjson to s3 and consume
it in a consistent way as with crossref data.

## usage

```
// use Convert to read a .xml.gz file from disk and write a corresponding .ndjson file
stats, err := pubmed2json.Convert(r, w)

// use NewDecoder to retrieve entity by entity without reading the entire file into RAM
dec := pubmed2json.NewDecoder(r)
for {
    rec, err := dec.Next()
    if err == io.EOF {
        break
    }
    if err != nil {
        log.Fatal(err)
    }
    // rec.Type is "article" or "deleteCitation"
    if rec.Article != nil {
        fmt.Println(rec.Article.MedlineCitation.PMID.Value)
    }
}
```
