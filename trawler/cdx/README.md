This module is a client library for the [Internet Archive CDX API](https://github.com/internetarchive/wayback/tree/master/wayback-cdx-server). It includes a CLI wrapper.

For now the client is used in the `trawler` project of Internet Archive Scholar and the CLI is compiled manually on demand to use in manual testing of the CDX API, but at some point this might be split out into its own repository for re-use.
