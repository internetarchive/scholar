This module is a client library for the [Internet Archive SPN API](https://archive.org/details/spn-2-public-api-page-docs-2023-01-22/page/2/mode/1up). It includes a CLI wrapper.

For now the client is used in the `trawler` project of Internet Archive Scholar and the CLI is compiled manually on demand to use in manual testing of the SPN API, but at some point this might be split out into its own repository for re-use.
